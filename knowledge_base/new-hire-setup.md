# New Hire Device and Account Setup

## Before day one
The manager submits the new hire request at least 5 business days before the start date. HR's record triggers account creation, and the laptop is pre-enrolled with Windows Autopilot.

## Day one
1. Power on the laptop, connect to Wi-Fi, and sign in with the work email.
2. Use the Temporary Access Pass from the manager to register Microsoft Authenticator (MFA).
3. Set a permanent password (14+ characters).
4. Company Portal installs standard apps automatically; role-specific apps are requested through the service portal.
