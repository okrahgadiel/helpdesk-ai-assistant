# Computer Running Slow

## Steps
1. Restart the computer — many issues come from pending updates or long uptime.
2. Open Task Manager (Ctrl+Shift+Esc) or Activity Monitor and sort by CPU and Memory to find the heavy process.
3. Install pending updates from Windows Update or Software Center, then restart again.
4. Make sure at least 15% of the disk is free; clear Downloads and empty the Recycle Bin.
5. Disable unneeded startup apps (Task Manager > Startup apps).

## Hardware
If the device is more than four years old or has under 8 GB of RAM, request a hardware refresh through the service portal.
