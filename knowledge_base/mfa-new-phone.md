# Set Up MFA on a New Phone

## Before you switch phones
If you still have the old phone, sign in to the security info page and add the new phone as an additional authenticator method before wiping the old one.

## Steps
1. Install Microsoft Authenticator on the new phone.
2. Open the security info page on a computer and choose "Add sign-in method" > "Authenticator app".
3. Scan the QR code with the Authenticator app and approve the test notification.
4. Set the new phone as the default sign-in method and delete the old device.

## Lost or replaced phone without access
Contact the service desk. After identity verification an agent will issue a Temporary Access Pass (TAP) valid for one hour so you can register the new device.

## Unexpected MFA prompts
Never approve a prompt you did not start. Deny it, change your password immediately, and report it to security — repeated unexpected prompts are an MFA fatigue attack.
