# Wi-Fi Keeps Disconnecting

## Steps
1. Forget the corporate Wi-Fi network and reconnect so a fresh certificate-based (802.1X) profile is applied.
2. Turn off power saving for the wireless adapter (Device Manager > Network adapters > Properties > Power Management).
3. Update the wireless driver through Software Center or the manufacturer's update tool.
4. Test on the guest network: if guest works but corporate does not, the device certificate may be expired — run a device sync from Company Portal.

## Building-wide outage
If multiple people in the same area lose Wi-Fi at once, report it as a network outage (priority 1) and include the building and floor.
