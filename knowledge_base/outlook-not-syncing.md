# Outlook Not Syncing or Not Receiving Email

## Steps
1. Check the status bar: "Working offline" means offline mode is on — go to Send/Receive and turn off Work Offline.
2. Check whether email works in Outlook on the web. If it does, the problem is the desktop app, not the mailbox.
3. Restart Outlook in safe mode (hold Ctrl while launching on Windows) to rule out add-ins.
4. Rebuild the Outlook profile: Control Panel > Mail > Show Profiles > Add a new profile, then set it as default.

## Mailbox full
Mailboxes over quota stop receiving mail. Empty Deleted Items and enable archiving to move older mail automatically.
